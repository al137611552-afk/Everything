# 路线图核对 · 0.3.1

依据原 interaction-spec.md 核对。当前仍是内测原型，不是已完成全部验收的发布版。公开源码已获得用户授权，替代初始闭源要求。

## 本次修复

- TextBox 模板重复计算 Padding，52 DIP 输入框的文字视口被压至 14 DIP；移除重复 Margin 后恢复为 32 DIP，可完整容纳约 25.4 DIP 高的文字。
- 右上角恢复设计稿的透明关闭按钮，移除额外的实体设置按钮。设置仍可通过搜索、空输入工具列表和托盘打开。
- 新增 --layout-test：中英文、下伸字母、长输入在 100/125/150/200% 布局缩放下共 16 项文字可见范围检查。布局缩放不是实机多显示器 DPI 切换测试。

## 已有基础实现

应用和系统工具启动、中文首字母匹配、Everything 全盘便携索引及查询、文件操作、翻译接口配置与复制、PowerShell 工作目录和简单收藏、区域截图、托盘、默认全局快捷键、异步查询取消和旧响应保护。

2. **日常启动体验**：置顶、最近使用、使用记录关闭及清除、别名编辑、同相关性下按频率排序、普通搜索混合最多三条文件结果。扩展商店应用发现与完整拼音属于后续增强。
3. **设置与依赖状态**：可修改全局快捷键和截图快捷键、冲突检测、开机启动、首次启动引导、关于页、Everything 重新检测和索引就绪状态；文件结果按需加载，目前最多 80 条。

5. **终端收藏完善**：名称、关键词、Shell、命令、工作目录、保留窗口选项的完整表单，以及编辑、删除和可审阅导入。当前仅简单保存名称、命令和目录。
6. **分发与更新**：正式安装器、卸载、版本更新检查和更新流程、版本说明及第三方许可展示、签名方案。目前交付的是便携 ZIP。
