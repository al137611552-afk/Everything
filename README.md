# Quick

面向 Windows 的本地快捷工具面板，免费使用。当前为 0.3.4 内测版本。仓库为公开源码存放位置；项目自身尚未选定开源许可证，不代表授予任意再分发许可。第三方组件遵循各自许可证。

## 功能

- 开始菜单应用搜索，常用中文首字母匹配。
- 记事本、计算器、画图、任务管理器和命令提示符直接入口，支持中英文与拼音别名。
- 内置官方 Everything 1.4.1.1032 和 ES 1.1.0.37 的打包流程，无需手填 CLI 路径。
- 优先连接已运行的标准 Everything；否则使用独立便携实例，默认索引所有已就绪的本地固定盘及移动盘；设置页直接显示磁盘范围。
- 区域截图、翻译服务配置、PowerShell 命令与收藏。
- C# / WPF 深色界面，透明圆角窗口、深色滚动条、分类下划线和系统应用图标。视觉方向来自图像设计工具，没有使用 JavaScript 绘制 UI。

## 构建

在 Windows x64、具备系统 .NET Framework C# 编译器和 WPF 运行库的环境运行：

```powershell
.\scripts\build.ps1
.\scripts\fetch-search-tools.ps1
```

输出为 `outputs/Quick-v0.3.4`。完整分发该目录的程序、Main.xaml、tools 和第三方许可证；**不要分发 data、用户配置或测试索引**。目前没有签名、安装器或自动更新。

## 使用

先退出托盘中的旧版本，再完整解压运行 Quick.exe，Alt+Space 唤起。输入应用名称打开；`f 关键词` 搜索文件；`tr 文本` 后 Ctrl+Enter 翻译；`> 命令` 进入命令模式。Tab 展开文件操作，Esc 返回。关闭按钮隐藏至托盘，右键托盘可退出。

翻译需在设置中填入完整 HTTPS Chat Completions 兼容接口、模型和自己的 API Key。只主动提交文字，不后台上传剪贴板。密钥使用当前用户 DPAPI 保存。

## 验证与限制

0.3 已通过系统应用发现、命令参数、中文字符、CLI 取消/失败处理等检查，以及真实 Everything 自动启动、索引与搜索测试。主窗口、设置窗口使用统一的无系统标题栏圆角边框。设置窗口已在实际桌面检查中确认移除顶部白边；21 项自动检查通过，全局索引实际搜到 Windows/System32/notepad.exe。

尚未完成：全套交互端到端测试、多屏截图兼容、翻译服务联网与正常桌面用户 DPAPI 验证、自定义全局快捷键、完整全拼搜索、所有商店应用发现。本轮已检查设置窗口外观和独立渲染，全套交互回归仍待完成。当前不声称逐像素还原全部设计稿。

默认便携模式现在扫描整块本地磁盘，不再限制为用户文件夹。首次扫描可能需要几分钟，只能读取当前账户有权限的路径，网络共享不会自动扫描。搜索范围全盘不代表采用 NTFS USN 快速索引；需要后者时可连接已经配置好的标准 Everything。新插入磁盘在重新启动面板后纳入索引。数据保存在面板目录下的 data/Everything，翻译和收藏配置保存在当前用户 LocalAppData/QuickPanelPreview。

## 0.3.2 修复

首次启动 Everything 返回代码 8（IPC 窗口未建立）时自动等待并重试，最长约 30 秒。等待状态明确显示，输入变更取消旧请求；其他错误立即报告。24 项自动检查通过，包括前两次返回代码 8 后同一次搜索恢复、连接超时、取消及其他错误不重试。DPAPI 仍有 1 项环境限制，未完成实机全套验收。

## 0.3.3 系统入口与网页搜索

控制面板支持中文、control、kzmb 和 kongzhimianban。输入 bd 搜索内容、zh 搜索内容、gg 搜索内容，按 Enter 分别在默认浏览器打开百度、知乎、Google 搜索；仅关键词时提示继续输入，不打开空页面。中文和特殊字符进行 URL 编码，输入期间不访问网站。30 项自动检查通过，网页搜索界面完成 WPF 渲染检查；网站加载及登录状态未完成浏览器端到端验证。
